===========================================================================================
File: /workspace/desi-models/player/player.glb   helper script: /workspace/desi-models/player/godot/player_rig.gd
Units metres, faces -Z, feet at y=0, 24 fps source. All clips are IN PLACE (no root motion; root bone is static,
pelvis has only bob/sway). Drive translation from the CharacterBody3D, and scale Walk/Run playback by speed:
  foot-contact speed measured in Blender: Walk 1.16 m/s, CrouchWalk 0.77 m/s (reliable); Run ~6.2 m/s and Sprint ~9.5 m/s
  (few contact frames, low confidence). If game speeds are lower, set AnimationPlayer speed_scale = game_speed / clip_speed
  (e.g. Run at 4.5 m/s -> 0.72) and tune by eye for foot slide.

SUGGESTED AnimationTree (AnimationNodeBlendTree)
  Locomotion  = BlendSpace1D/2D on speed: Idle / Walk / Run / Sprint ; Crouch / CrouchWalk under a crouch Blend2.
  Air         = Jump (one-shot) -> Fall (loop) -> Land (one-shot) via a StateMachine fed by is_on_floor().
  UpperBody   = StateMachine: Hold_Rifle (default with a gun) <-> ADS_Aim (xfade 0.12 s); Fire as a OneShot (fadein 0,
                fadeout 0.05) on top; Reload as a OneShot; Throw as a OneShot (fadein 0.1).
  Combine     = Blend2 with a bone filter = spine_02, spine_03, neck_01, Head, clavicle_*, upperarm_*, lowerarm_*, hand_*,
                all finger bones (_l and _r). Locomotion feeds the base input, UpperBody the blend input (amount 1).
                Optional: add 30-50% of spine_01 too if the rifle wobbles with the run cycle.
  Override    = top-level Transition (no blend filter): Alive (Combine) / Downed / Reviving (ReviveStart -> Revive loop
                -> ReviveEnd) / Dead (Death, hold last frame). Downed and Death are full body; disable the upper-body
                layer in those states. The reviver plays Revive; the downed player stays in Downed.
  Aim pitch   = not baked; add a SkeletonModifier3D/LookAt or rotate spine_03 (+/-) by camera pitch after the tree.
NET SYNC: replicate only state (loco speed/dir, crouch, airborne, ads, firing tick, reload start time, throw start, downed,
  reviving, dead, player_index). Each client plays its own AnimationTree; one-shots are triggered from replicated events.

PER-PLAYER TINT API (4 co-op players)
  The fluoro fabric of every hi-vis band (forearms, upper arms, chest, waist, shins) and the beanie knit are surface 1
  "TintBand" on player_body. Its texture is near-white worn fabric, so albedo_color = the player colour.
  Reflective strips, gloves, jacket etc. stay on surface 0 "Player" (never tinted).
    var mi: MeshInstance3D = $player/player_rig/Skeleton3D/player_body
    var m := mi.mesh.surface_get_material(1).duplicate() as StandardMaterial3D
    m.albedo_color = Color("#C9D12B"); mi.set_surface_override_material(1, m)
  or attach player_rig.gd to the instanced root and set player_index 0..3 (it also sets the loop flags).
  Presets (sRGB): P1 Fluoro Orange #D9601F (= fp_arms default) | P2 Hi-Vis Yellow #C9D12B |
                  P3 Signal Cyan #1E9FC8 | P4 Safety Magenta #C2307A
  Glow at night (optional): m.emission_enabled = true; m.emission = colour; m.emission_energy_multiplier = 0.15-0.3.

GUN NOTES (G4M3N): Hold_Rifle/ADS_Aim/Fire/Reload were posed on weapons/weapon_assault_rifle.glb (SightPoint 0.04/0.146,
  handguard ~0.30 m ahead of the grip). Other long guns fit the right hand exactly (WeaponR); the left hand will sit at
  the AR handguard position, so for the LMG add a two-bone IK on the left arm (SkeletonIK3D / TwoBoneIK3D) targeting
  the gun's Underbarrel socket, and for pistols/hand cannon use ADS_Aim with the left hand IK'd to the right hand or a
  dedicated pistol layer (not authored). ADS sight alignment is exact for the AR only; for other sights offset the
  camera by (gun SightPoint - AR SightPoint).
