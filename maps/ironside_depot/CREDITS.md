place** (not copied or moved), so they cost no extra disk. Only the procedural decals below are new files.

## New in this map (phase 2): `assets/decals/` (508 KB, made for this project, CC0 1.0)
Generated by `tools/make_ironside_decals.py` (procedural noise + DejaVu Sans text, all 512 px or smaller):
oil_stain, grime_streak, hazard_stripe, platform_edge, blood_smear, and the room signs sign_platform, sign_booking,
sign_loading, sign_cold, sign_sorting, sign_yard, sign_coal, sign_engine, sign_roundhouse, sign_fuel.
(Sign text is rasterised DejaVu Sans; the DejaVu/Bitstream Vera font license permits this, and no font file ships.)
